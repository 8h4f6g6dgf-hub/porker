# Luxury Private Poker Salon — 3D environment

## 実装
`VipRoom.tsx`で写真背景と写真を投影する床を置換。
`CasinoScene.tsx`は旧Roomの呼び出しのみ置換し、CameraRail/Table/Dealer/Cards/Chipsの
実装・座標・形状・アニメーションは変更していない。教材・字幕・クイズも変更なし。
旧CasinoBackdrop/CasinoFloorは参照されず実行されない。背景写真への通信がないことをE2E検証。

床y=-1、背面z=-6.2、左右x=±5.8、天井y=3.5（既存シーン単位）。
厚みのある木製壁、立体パネル、面取りされた額縁状モールディング、巾木、
二段の天井コーニス、折り上げ天井、右奥の木製ドアを構築。
静的な建築パーツを材質別5メッシュへ結合し、繰り返し装飾の描画負荷を抑制。
椅子や人物、環境音は追加していない。

## 素材
Poly Haven Wood Table 001、Dimitrios Savva / Rico Cilliers、CC0。
詳細はpublic/assets/vip-room/README.md。1K JPEGの色・OpenGL法線・粗さを使用。
3枚計504,761 bytes。外部APIへ実行時通信しない。
カーペットの織り目と接地影はコード生成。床はPBRのroughness/bumpを使用。
木材ロード失敗時は同じ解像度の代替マテリアルを維持し、カード操作を止めない。

## 照明
壁灯2基に対応する暖色灯、天井の間接光、環境光、テーブルのキーライト。
キーライトは天井器具位置[1,3.4,1.5]へ移動。影は従来同様1灯・1024pxのみ。
顔へ正面から当てる新しい光源は追加していない。
壁灯は旋盤形状のシェードと真鍮の支持具。派手な発光や点滅なし。
床は不透明・depth書き込みあり。テーブルの脚は既存の床y=-1へ接地し、
柔らかい接地影とキーライトの影を併用。

## 検証・負荷
PC1440×900、横画面844×390および667×375で、実描画と既存学習操作を確認。
67単体テスト、14ブラウザテスト、GitHub Pages向けビルド成功。
52枚カード検証、WebGL非対応、木材ロード失敗、保存・クイズを含む。
既存の500KB超chunk警告は継続（3D依存を含む）。

同じChrome/headlessで、導入後の選択画面を旧版と新版で順に計測：
- 描画calls: 80 → 91（+11）
- 三角形: 22,146 → 29,834（+7,688）
- resident textures: 8 → 11
- 60フレームの中央値: PC/横画面とも旧新33.3ms（約30fps）
これは開発マシンとheadlessの観測値であり、実機スマホのfps保証ではない。
部屋用画像の転送量は旧写真260,598 bytesに対して504,761 bytes（約244KB増）。
GPU画像メモリは旧写真約6MBから、PBR3枚＋生成画像約17MBへ増加（概算）。
写真比で本物の幾何形状・法線マップの負荷が増える。実機計測は未実施。

## 品質上の制約・次の改善
3D個室への移行と機能検証は完了したが、写真同等の写実品質とは評価しない。
ベイクした間接光や反射環境は未導入で、木目反復・壁灯シェードの表現は改善余地がある。
固定下向きカメラでは天井の大半が画面外。カメラを変えて見せる調整はしていない。
ディーラー人体モデルの問題は既存のままで、改善済みと扱わない。
今後は壁ごとのUV変化、ベイク照明、実機モバイル検証を優先する。
