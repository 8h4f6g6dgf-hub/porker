# リグ付きディーラーの導入

## 素材と実装

Quaternius Universal Base Characters の無料 Standard 版に含まれる `Superhero_Male_FullBody` を採用。CC0 1.0。公式出典と同梱ライセンスは `public/assets/dealer/README.md` と `License_Standard.txt` に保存。商用利用・改変・Web配信・公開リポジトリでの再配布が可能。有料 Source 版、Mixamo、有料APIは使用していない。

元の一体型人体メッシュと65ボーンのスキニングを維持し、白シャツ・黒スラックス・暗い頭部のマットな配色へ変更。黒ベストは元の胴体表面を襟ぐりで切り出し、外側へオフセットして生成。切断点のウェイトを補間し、襟・ネクタイも同じリグへ接続。画像テクスチャは使わない。

`dealerMotion.ts` は肩・肘の2ボーンIK、手首姿勢、軽い指曲げを制御する。Idleは微かな呼吸、Dealは各カード配布に合わせた短いストローク、Presentは着地後にカード方向を軽く示す。カードの飛行時間と配布間隔は維持し、移動前に180msの予備動作を追加。フロップ最終着地は1.37秒で既存の1.4秒操作ロック内。急な状態変更は骨回転を補間し、後方チャプター移動では配布を再実行しない。動きを減らす設定も尊重する。

カメラ・内装・テーブル・椅子・カードデザイン/最終位置・チップ・教材・字幕・クイズ・保存処理・Pages設定は変更していない。

## 読み込みと負荷

非同期GLBロード。ロード中・失敗時は既存ディーラーをフォールバックとして表示し、学習操作を継続。画面を離れた場合はモデルのメモリを解放し、遅れて完了した読み込みも破棄する。

- GLB: 845,556 bytes、gzip 約308KB（配信時の圧縮方式はホストによる）
- 65ボーン、2つのスキニング済み描画プリミティブ、画像テクスチャなし
- Riverの描画: 123→70 draw calls、81,410→101,114 triangles（影などを含む描画統計）
- 3Dチャンク gzip: 約262→277KB。既存の大きなチャンク警告は残る。
- 同一MacのヘッドレスChromeで各180フレーム測定：改修前後ともPC/844×390で中央値16.7ms、95%点16.7〜16.8ms。実機スマートフォンのGPU性能・通信速度を保証する測定ではない。

## 検証

- 自動テスト77件：既存74件に、GLBのウェイト/骨構造、各モーションでの手メッシュとフェルトの非貫通、カードとのタイミング検証を追加。
- 既存ブラウザテスト14件：教材全体、30問、保存、PC/スマホ横画面、WebGL非対応、動きを減らす設定など。
- 追加ブラウザテスト：正常ロード後にGLBの取得を意図的に失敗させ、代替表示で導入レッスンとクイズ回答が可能であること。
- 1440×900 / 844×390で同じRiver場面の前後比較、Deal/Presentも撮影。画像はローカル `docs/screenshots/rigged-dealer/` に保存。

## 残る品質上の制約

無料Standard版は筋肉質な体型で、腕や服の表現はゲーム向けの簡略化が残る。スーツ専用の縫製・袖のシワ・肌質・髪は再現していない。顔は既存照明下の暗がりに置き、表情はない。指先による厳密な把持やカード接触の物理演算は未実装。モデル更新として導入可能な段階だが、衣装と手指の最終品質まで完成したとは扱わない。実機スマートフォンでの長時間検証は未実施。
