# VIP room interior refinement

## 変更範囲
実装差分はVipRoom.tsxのみ。CameraRail・Table・Dealer・Cards・Chips・字幕・教材は変更なし。
写真背景には戻さず、既存のPBR素材（Poly Haven Wood Table 001、CC0）を再利用。
外部素材・依存・画像ダウンロードは追加していない。

## 壁・空間
6枚の明るい上段パネルと水平の腰見切りを廃止。
背面中央を3枚の深緑の布張りパネルで構成し、木製の深い枠と細い真鍮の縁取りで囲む。
左右は幅の異なるウォルナットのパネルと細い溝付きの柱、右奥は木製ドア。
側壁は幅を変えた5区画と一部布張り。木目のUVオフセットも変え反復を軽減。
木の反射を抑え、布のbump強度は微細な織り目相当へ低減。透過材は使用しない。

既存シーン単位（実寸mとして校正した値ではない）：
- 背面内壁z: -6.2 → -8.4（2.2後退）
- 側壁内面x: ±5.8 → ±6.4（幅11.6 → 12.8）
- 天井下面y: 3.5 → 4.0、床y=-1は維持
- 床奥行き: 14.5 → 16.7
- ディーラー中心z=-2.24から背面壁まで: 3.96 → 6.16
カメラやテーブルの移動・縮小で広く見せる方法は使っていない。
巾木・コーニス・床を同時に延長し、壁の接合部は厚みを持って重ねている。

## 照明
壁灯を背面から左右の側壁へ移し、低い視点から光源と照らされる壁が分かる配置にした。
2個の広域pointLightを2個の暖色spotLightへ置換し、天井から背面を柔らかく照らす。
白寄りの補助光を暖色へ変更。ambient .38→.26、hemisphere .55→.30。
壁灯と背面灯は#ffbd80を使用（暖色の演出であり、測色によるCCT保証ではない）。
木材・布の弱いemissive成分で二次反射を近似。木材は同じ色マップを併用し模様を保つ。
これは光輸送を計算したベイクではない。テーブル材質には加えていない。
キーライトの位置・強度は前版を維持。天井を上げた分の支持部を追加した。
リアルタイム光源はpoint/spot計7灯のまま、影を描くライトは1灯・1024pxのまま。
新しい人物・音声・家具は追加していない。

## 検証
同じRiver学習シーン・カメラで1440×900、844×390、667×375を撮影。
画像: docs/screenshots/vip-refinement/{before,after}/。
67件の単体テスト、14件のブラウザテストが成功。
最終の材質微調整後、3D・WebGL非対応・素材ロード失敗の7件を再実行。
GitHub Pagesビルド成功。従来のchunk-size警告は継続。

同じheadless Chromeの導入後選択画面での比較：
- calls: 91 → 91
- triangles: 29,834 → 31,970（+2,136）
- textures: 11 → 11
- 60フレームの中央値: 旧新ともPC/横画面33.3ms（約30fps）
静的な構造は材質別に統合したまま。新しい画像配信や追加GPUテクスチャはない。
これらは開発マシンでの観測値であり、実機スマホのfps保証ではない。

## 未解決・限界
実機スマホの検証、物理ベイクの間接光、反射環境の精密化は未実施。
天井は高くしたが、固定カメラの下向き構図では大部分が画面外。
木材と布の見え方は画面輝度にも依存し、暗い端末では側壁の詳細が見えにくい可能性がある。
現状は静かな3Dサロンの表現で、写真同等の写実品質を保証するものではない。
ディーラーの人体品質は今回の対象外のまま。
