# ディーラー最終ビジュアル調整

前回の調整記録。最新の修正は [参考画像に基づく修正](DEALER-REFERENCE-REFINEMENT.md) を参照。

今回で人物の外観調整を一区切りとし、追加の高精細化は行わない。

## 変更内容

- 65ボーンと元の人体トポロジーを維持。肩を左右約0.04ずつ内側へ寄せ、肩関節間を約0.784から0.702へ縮小。全身スケール1.85は変更していない。
- 上腕・前腕の断面を骨の影響度に応じて約26%・28%抑え、胴体は最大4.5%の幅、12%の厚みを調整。再計算した法線で陰影を整えた。
- 手を手首中心に8%小さくし、指の階層も一緒に追従させた。
- ベストのVネックを細く自然な形へ変更。襟とネクタイは実際の胸の表面へ投影し、同じ面からスキニングの重みを補間。ネクタイを結び目・細い本体・剣先のある形へ変更。肩の色境界と腰部の白い線を修正した。
- 待機手首を `(±0.38, 0.905, -1.64)` から `(±0.34, 0.823, -1.48)` へ移動。手の下向き角度を約8°から約1.4°へ弱め、親指の反りを抑制。軽い前傾で無理なく届く姿勢へ調整。
- 待機時の手の下面はフェルト面から約0.0033シーン単位。20秒分の呼吸周期を含めて非貫通を検証。Idle / Deal / Presentのタイミング、カード配布同期、読み込み失敗時の代替表示は維持。

カメラ、テーブル、椅子、内装、照明、カード、チップ、字幕、教材、クイズ、保存、GitHub Pages設定は変更していない。新しい外部素材や有料サービスは追加していない。

## 検証

- 同じRiver場面・同じカメラで1440×900と844×390の前後を比較。Deal / Presentも撮影。
- 自動テスト78件。手の接地距離、肩幅、指先の傾き、親指姿勢の検証を追加。
- ブラウザテスト15件が成功。モデル読み込み失敗時を含め、教材・クイズ・保存・横画面・WebGLフォールバックを検証。
- 同一MacのChromeで前後各180フレームを比較。PC/スマホ横画面とも中央値16.7ms、95%点16.7〜16.8msで、大きな悪化は見られなかった。
- GLBは880,076 bytes（gzip約346KB）。65ボーン、2つのスキニング描画プリミティブを維持。
- Riverの描画統計は70 draw callsを維持、三角形101,114→101,534（影などを含む）。画像テクスチャ・ライト・影の追加なし。
- ビルドの既存チャンクサイズ警告は残る。
- 比較画像はローカル `docs/screenshots/dealer-final/before/` と `after/` に保存。

## 残る軽微な表現上の制約

低ポリゴンモデル由来の襟・袖の角張り、簡略化された布のシワは残る。指先によるカード把持や布シミュレーションは行わない。スマホ横画面はブラウザ上の画面サイズで検証しており、実機スマートフォンでの長時間測定ではない。これらを今回の範囲外とし、ディーラーの外観改善を一旦完了とする。
