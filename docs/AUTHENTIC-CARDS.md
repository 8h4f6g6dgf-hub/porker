# Authentic playing cards

## 素材と変更範囲
SVG-cards 4.0.2（David Bellot / Huub de Beer、ほか AUTHORS 記載）を採用。
出典・固定コミット・LGPL-2.1全文・編集可能な元SVGを
`public/assets/cards/` に同梱。商用利用・改変・Web配信・公開リポジトリ収録が
ライセンス条件下で可能。派生SVGもLGPL-2.1。詳細は同ディレクトリのREADME。

Aは中央1個、2〜10は伝統的なピップ配置、J/Q/Kは各スートの上下対称の人物画。
既存の表面テクスチャだけを交換。裏面・形状・配置・演出・カメラ・背景・教材は変更なし。
元データから参照定義だけを抽出する再生成スクリプトも収録。

## 配信とGPU
52枚の独立SVGは合計967,380 bytes、最大82,294 bytes。
現在の7枚の合計は209,899 bytes（HTTP圧縮前）。元SVGは実行時に読み込まない。
表示するカードだけを512×720 CanvasTextureに変換し、アンマウント時にdispose。
HTTPキャッシュを利用し、52枚分を事前GPUロードしない。
表面1枚のRGBAは約1.4 MiB（mipmap別）、従来と同解像度。
StrictModeのeffect再実行でも非同期画像の描画結果が失われないようにした。
読み込み失敗はconsoleに記録し、学習機能は継続できるが、その面は白くなる。

## 検証
ブラウザテストは実際のSVG要素を解析し、数札のスート参照数から
インデックス2個を除いた中央ピップ数を全40枚で検証。
全52枚の同一ランク参照・反転インデックス・赤黒、12枚の人物参照と反転を検証。
52枚すべてを実際のCanvasTextureにデコードし、一覧画像を取得。
PC1440×900、横画面844×390・667×375の3D表示と既存学習フローも確認。
既存63単体テスト、13ブラウザテスト、GitHub Pages向けビルドを使用。

## 制約
横画面確認はデスクトップChromeのビューポート検証であり実機計測ではない。
SVGのランク書体は元素材のDejaVu Serif指定（未搭載端末はserifへフォールバック）。
カード単体で拡大可能なベクターを配信するが、3D上では512×720にラスタライズする。
ディーラー品質など、今回の対象外の未完了事項は改善済みとして扱わない。
