# 参考画像に基づく3Dディーラーの修正

## 原因と対応

元のQuaterniusモデルの眼球・眉メッシュは+Z側にあり、モデルの正面は+Z。従来はY軸を180°回転して背面側に衣装を生成していた。今回、正面をプレイヤーへ向け、衣装の投影と手の向きを同じ基準へ修正した。

左右反転で作った襟は片側の三角形の向きが逆になっていたため、両面マテリアルの陰影が反転して黒い重なりに見えていた。衣装の面方向を法線に揃え、回帰テストを追加した。

添付画像は体型・衣装・手の配置の参照だけに使用。画像をアプリに収録・表示していない。既存のQuaternius製3Dメッシュ、65ボーン、CC0表記を維持。

## 最終調整

- 肩関節間：約0.702→0.662。上腕・前腕の実効断面を前回から約14%細くし、胸の厚みを抑えた。ウエストは滑らかな曲線で絞り、モデル全体の横圧縮は行っていない。
- 肩の高さ：約1.633→1.715。背骨の前傾を約19.5°から約2.9°へ戻し、胴体・腕の長さを調整。襟が画面上端で切れすぎない高さを同じカメラで選んだ。全身スケール1.85・床位置は維持。直立姿勢でも手が届くよう、ディーラーのみZ=-2.05から-1.88へ調整。
- 腕の骨は均等スケールで伸長し、袖の断面と手の継承スケールを補正。非均等スケールによるねじれを避けている。手の実効スケールは元モデル比0.88。
- 肘を身体の横へ戻し、手のひらを下へ向けた。親指を跳ね上げず、指先は軽く伸ばしてテーブルへ添える。肩・肘・手首のIKとIdle / Deal / Presentのタイミングを維持。
- Vネック、左右の襟、ネクタイの結び目・本体・剣先を修正。襟とネクタイを細分化して胸表面に投影し、途中で身体に埋まることを防止。ネクタイ下の白い隙間を除去し、控えめなボタンを3個配置。

カメラ、テーブル、椅子、内装、照明、カード、チップ、字幕、教材、クイズ、保存、Pages設定は変更していない。配布開始・間隔・飛行時間は変更なし。モデルロード失敗時の代替表示も維持。

## 検証と容量

- 自動テスト80件。65ボーン・スキニング、20秒の待機周期を含む手とフェルトの非貫通、配布タイミング、肩幅・姿勢、下向きの手のひら、肘の角度、衣装の面方向を検証。
- ブラウザテスト15件：全教材・30問、字幕送り、保存、PC/横画面、WebGL非対応、モデル取得失敗時を検証。
- 1448×1086と844×390の同じ「TAKE A SEAT」場面で前後比較。1440×900と844×390のRiver、Deal、Presentも撮影。
- 画像はローカル `docs/screenshots/dealer-reference/before/` と `after/` に保存。`detail.png` は同じカメラの首元・腕を切り出したブラウザ撮影。
- GLB 886,564 bytes（約0.89MB）、画像テクスチャ追加なし。描画呼び出し70を維持、Riverの描画三角形は101,534→102,054（影を含む）。
- ビルド成功。既存の大きな3Dチャンク警告は残る。

## 表現の範囲

参考画像の写真的な布・肌の質感まで一致させたものではない。低ポリゴン由来の袖・襟の角張りや簡略化した布のシワ、指先の厳密なカード把持は残る。新しい有料素材・API・人物画像は使用していない。スマホは横画面サイズでのブラウザ検証で、実機での長時間性能測定は未実施。
