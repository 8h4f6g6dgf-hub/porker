# Poker Academy 2.0 — 実装・検証記録

2026-11-07。最初の約3分間を対象とする操作可能なプロトタイプ。読む速さ・音声・操作待ちによって所要時間は変わり、3分で強制終了しません。

## 実装内容

- `/` と `/experience`：暗転からのカメラ移動、着席、ACADEMY / CASINO / MY PROFILE、手札2枚の配布・反転、フロップ3枚→ターン→リバー、最初の三択問題、既存Lesson 01への接続。
- `/casino`：Academyと同じ3Dコンポーネントを照明違いで再利用。見学専用・Coming Soonを明示。
- `/lobby`：従来ロビー。`/casino/classic`：従来テーブル。教材・プロフィール・設定の既存ルートを維持。
- ディーラーは胸元・袖・手に絞った手続き的なモデル。黒いベスト、控えめなネクタイ、白いシャツ。手元を動かし、山札の二分割シャッフル、配布時の腕振り、説明中の微動を表示。
- Three.js / React Three Fiberの本物の3D描画。自由移動なし。固定のカメラ軌道と着席視点。カードには厚みがあり、配布中はテーブル上を移動し、反転時に少し持ち上がります。カードを直接タップ、または44px以上のHTMLボタンで操作できます。
- 日本語字幕とWeb Speech API。音声ON/OFF、再生、音声スキップ、日本語音声選択。効果音と音声の独立した音量。ユーザー操作後に再生を開始する設計で、外部有料APIは不使用。
- 初回演出6秒、再訪時短縮、明示的スキップ。各教材ステップは手動で進められ、音声再生中もスキップできます。

## 3D構成・パフォーマンス

- 深緑のフェルト、木目、カードのテクスチャをCanvasで生成。実行時の外部アセット取得なし。
- Standard/PBR材質（roughness / metalness）、ウォーム照明、影用ライト1個・1024pxシャドウ、霧。高負荷のポストプロセスなし。
- チップは同素材のジオメトリを統合して描画呼出しを削減。3Dは遅延ロードし、通常教材から利用時以外はロード不要。
- DPR上限1.5。非表示タブの描画停止。OSとアプリのreduced-motionを反映し、カメラ移動・配布移動・手の微動を抑制。
- WebGL2が使えない場合はカードの軽量表示へ移行。設定から軽量表示／3D再試行を選択可能。3D描画エラーもフォールバックします。
- 横画面の字幕と操作欄を3Dのカード表示領域から分離。セーフエリア対応。スマホ縦画面は従来どおり回転案内。

## 既存機能と履歴の保護

- 10レッスン・30問、役判定、元の解説・出典、レッスン履歴を削除せず維持。
- localStorageの学習スキーマ1を維持。導入問題のIDは `intro-v2-hole-cards`、問題版2.0.0、元レッスン01の版1.0.0として記録。
- 導入を終えても元のLesson 01を修了扱いにしません。すでにある進捗・修了状態を上書きしません。
- 導入の既読と音声設定は別キー。移動・再読み込み時に音声を停止。過去の成績を再計算しません。
- GitHub側で追加されたPagesワークフローをそのまま維持し、Pagesは `/porker/`＋HashRouter、Sitesは `/`＋BrowserRouterでビルド。
- サイトのURL（オリジン）が変わればブラウザの保存領域も異なります。SitesとGitHub Pagesの履歴は自動同期されません。

## 検証

- Vitest / React Testing Library：59件成功（既存45件を含む）。シナリオ遷移、両手札確認ガード、不正解、二重回答防止、既存履歴保護、軽量表示、音量独立・保存、音声終了処理を追加。
- Playwright：11件成功（既存6件を含む）。1440×900・844×390・667×375で3D導入→既存教材→保存復元、WebGLなし、reduced-motion、再訪短縮、CASINO共通シーン。既存教材は1024×768を含む4サイズと全30問を再確認。
- `npm run build` と `GITHUB_PAGES=true npm run build`：両方成功。
- 3Dチャンクは約952KB（gzip約256KB）。Viteの500KB警告は残ります。3D画面のみに遅延ロードされます。

## 制約と次の改善

- **写実的な完成版ではありません。** 人体はスキャンモデル／モーションキャプチャではなく、手続き的な胸元・手のモデルです。布の自然な皺、指の細かな把持、実写品質の皮膚・筋肉・物理シャッフルは未実装。次段階は許諾済みの高品質な手／袖モデル、リグと手付けモーションへの置換です。
- 端末の日本語音声に依存します。低めのピッチに調整し、利用可能なら男性名の声を優先しますが、男性の声や同一の音質は保証できません。音声が使えなくても字幕とボタンで進行します。
- 台詞単位の字幕です。音素単位の口・指・カード同期や録音済みプロナレーションは未実装。配布と説明はシナリオのフェーズ単位で連動します。
- iPhone Safari / Androidの実機GPU性能と実音声の聴取は未検証。Chromeの画面サイズ変更による確認です。低性能端末は軽量表示を利用してください。
- CPU・オンライン対戦、換金・決済・実際の金銭を賭ける機能は実装していません。
