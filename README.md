# Poker Academy — Version 2.0 Prototype

**2.0の追加内容・検証・制約は [実装記録](docs/PROTOTYPE-2.0.md) を参照してください。** 起動時に一人称3Dの導入が始まり、既存ロビーは `/lobby` から使えます。

無料でテキサスホールデムを学ぶ、日本語の横画面向けWebアプリ。React / TypeScript / Vite / Tailwind CSS / Motion / React Routerで構築しています。実際の賭博、チップ購入、換金機能はありません。

## 起動

Node.js 24で検証済みです。

```bash
npm ci
npm run dev -- --port 5173
```

http://127.0.0.1:5173/ を開いてください。

```bash
npm test           # 教材・数学・役判定・保存・UIテスト
npm run build      # TypeScript型チェックと本番ビルド → dist/
npm run test:e2e   # 起動済み開発サーバーに対するChromeブラウザテスト
```

ブラウザテストはmacOSのインストール済みChromeを使用します。別環境では `CHROME_PATH` にChrome/Chromium実行ファイルの絶対パスを指定してください。モバイル実機ではなく、Chromeのビューポートを変更した検証です。本番配信時は `/lesson/*` などのルートを `index.html` にフォールバックさせるSPA設定が必要です。

## 実装した機能

- アーチ、金色の間接照明、床、木製レールと緑のフェルトによるロビー／学習室／カジノの表現。画像の外部取得は不要です。
- LOBBY、ACADEMY、LESSON PLAYER、CASINO、MY ROOM、設定のルーティング。
- 10レッスン、各3問、合計30問。四択、二択、役判定、ハンド比較、アクション選択、数値入力。
- 全52枚の表現、カード配布・反転・選択のMotion演出、7枚から5枚を選ぶ役判定、ラウンド送り（左右スワイプ対応）、ボタン移動、チップ追加。
- 回答の正誤、理由、注意点、関連知識、根拠の表示。回答済みボタンをロックして二重採点を防止。
- localStorageへの進捗・回答・日時・教材版・問題版の保存と再読み込み。保存失敗は明示し、破損／未知スキーマを自動上書きしません。
- MY ROOMで実データから完了数、総回答数、正答率、分野別正答率、復習対象、直近15件の履歴を算出。
- 設定で動きの軽減、学習データのJSON書き出し、確認付きリセット。OSの動き削減設定にも対応。
- レッスン修了から約2.1秒の段階演出でCASINOへ移動。スキップ可能。
- 縦画面の回転案内、横画面レスポンシブ、セーフエリア、独立スクロールする解説パネル。

## 情報源と検証状況

2026-11-05に以下の公開本文を確認しました。説明文・例題は独自の日本語で作成し、第三者の教材、図表、レンジ表を複製していません。

- **RULE / VERIFIED:** [PokerStars — How to Play Texas Hold’em](https://www.pokerstars.com/poker/games/texas-holdem/)。基本ルール、ブラインド、アクション、進行、役の順位。
- **RULE / VERIFIED:** [Poker TDA — 2026 Rules v1.1](https://www.pokertda.com/view-poker-tda-rules/)。13〜23のショーダウン／分配、45のレイズ額、49のベット再開。TDAはトーナメント規則であり、施設別ルールと完全に同一とは限りません。
- **MATH / VERIFIED:** 本リポジトリの独立計算とテスト。組合せ数、確率、Call差額、最小Raise、ポット合計、期待値を検証。フラッシュドローの2枚抽出確率は全組合せの列挙とも照合。
- **STRATEGY / CONTEXT_DEPENDENT:** PokerStarsのStarting hands・positionの説明。判断が条件に依存することだけを説明し、万能な参加レンジを提示していません。
- SOLVER解析は未使用。未検証教材は公開対象外です。カテゴリーと検証状況は別フィールドで管理します。

数式の前提：未見カードが等確率で現れる非復元抽出。ポットオッズの例は追加ベットなし、レーキなし、引き分けなしの1対1。完成確率をそのまま勝率とは扱いません。

## 主要ファイルと拡張方法

- `src/domain/types.ts` — 教材、問題、出典、テーブル、履歴の型。
- `src/domain/poker.ts` — UI非依存の役判定（5〜7枚）、比較、確率、チップ計算、採点。
- `src/data/lessons.ts` — 10教材・30問、前提関係、教材更新履歴。
- `src/data/sources.ts` — 根拠ID、参照先、確認日、参照箇所、検証方法、注意事項。
- `src/components/Table.tsx` — PlayingCard、CardDeck、PokerChip、ChipStack、PlayerSeat、DealerButton、CommunityCards、PokerTable。
- `src/components/Learning.tsx` — ActionButtons、ExplanationPanel、LessonProgress、SourceReference。
- `src/persistence/storage.ts` — 交換可能なLearningRepository、スキーマ検証、集計。
- `src/persistence/context.tsx` — 状態と永続化の接続。
- `src/App.tsx` — ルーティングと各画面、学習フロー。
- `src/styles.css` — 共通デザイン、横画面、セーフエリア、動き軽減。
- `src/tests/` — Vitest / Testing Library。
- `e2e/app.spec.ts` — Playwrightによる全教材と画面サイズ検証。
- `CHANGELOG.md` — アプリ更新履歴。教材の個別履歴は `curriculumChanges`。

教材追加は `Seed` データ、根拠、更新履歴を追加します。MAJORは目標／構成変更、MINORは問題追加、PATCHは軽微修正を原則とし、採点変更時は問題版も上げます。既存回答には版と当時の正解・判定を残します。オンライン同期導入時はLearningRepositoryを実装し、スキーマの明示的な移行処理を追加してください。現時点のスキーマは1です。
